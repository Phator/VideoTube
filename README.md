# VideoTube — ASP.NET Core MVC Learning Project

VideoTube is a simple, experimental video‑sharing website built as part of my journey learning **ASP.NET Core MVC**.  
This is **not** a production application — it’s a **test site** created to help me understand how MVC works, how controllers and views interact, and how to build real web features using C#.

---

## 🎯 Purpose

This project exists purely for **learning**.  
I’m using VideoTube to practice:

- ASP.NET Core MVC architecture  
- Controllers, Views, and Models  
- Entity Framework Core  
- Razor pages  
- Routing  
- File uploads  
- Basic CRUD operations  
- Working with thumbnails and media files  
- Bootstrap UI layout  

Everything here is experimental and part of my personal development.

---

## 🧩 Features (Learning‑Focused)

- Upload videos  
- Display thumbnails  
- Watch videos  
- Delete videos  
- Categorize videos  
- Search videos  
- Show video cards with title, views, and thumbnail  
- Basic Bootstrap styling  

These features are intentionally simple — they exist to help me understand MVC patterns.

## 🛠️ Tech Stack

- **ASP.NET Core MVC**

- **Razor Views**  
- **Bootstrap 5**
